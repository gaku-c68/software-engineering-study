# プログラミング言語の違いと使い分け

プログラミング言語には、JavaScript、Python、C、Java、Rustなど、さまざまな種類があります。

どの言語でも似たような処理を実装できることがありますが、実際の開発では、作りたいものや動作する環境によって使われる言語が異なります。

では、なぜWeb開発ではJavaScriptが使われ、AI開発ではPythonがよく使われるのでしょうか。また、スマートフォンアプリやゲームでは、どのような理由で言語が選ばれるのでしょうか。

この授業では、代表的なプログラミング言語の特徴を比較し、**言語の違いを理解したうえで、開発目的に合った技術を選ぶ考え方**を学びます。

## この授業で学ぶこと

- 代表的なプログラミング言語の特徴と用途
- 言語による型の扱い方や実行環境の違い
- 言語とライブラリ・フレームワークの関係
- 開発するものに応じた言語の選び方

## 1. なぜプログラミング言語はたくさんあるのか？

プログラミング言語は、すべて同じ目的で設計されているわけではありません。

例えば、Webページを操作するプログラムと、ゲームの描画を高速に処理するプログラムでは、求められる機能や性能が異なります。

また、言語そのものの特徴だけでなく、利用できるライブラリや開発ツール、既存のシステムとの互換性なども、言語が選ばれる理由になります。

つまり、**どの言語が最も優れているかではなく、どの言語が目的に適しているか**を考える必要があります。

## 2. JavaScriptとTypeScript：Web開発で使われる言語

### JavaScriptとは？

JavaScriptは、Webブラウザー上で動作するプログラミング言語です。

Webページを構成する技術には、主に次の3つがあります。

| 技術 | 役割 |
| --- | --- |
| HTML | ページの構造や意味を定義する |
| CSS | 色や配置などの見た目を指定する |
| JavaScript | ユーザーの操作に応じた動作を実装する |

例えば、ボタンをクリックするとメニューが開く、入力した内容に応じて表示が変わるといった機能は、JavaScriptで実装できます。

ブラウザーはクリックなどの出来事をイベントとして扱い、JavaScriptはDOMという仕組みを利用してページの内容を変更できます。

### なぜJavaScriptがWeb開発で使われるのか？

大きな理由は、主要なWebブラウザーにJavaScriptの実行環境が標準で備わっていることです。

また、JavaScriptはブラウザーだけでなく、Node.jsなどの実行環境を使うことでサーバー側でも動かせます。

そのため、Webアプリケーションの画面とサーバーの両方をJavaScriptで開発することもできます。

### TypeScriptとは？

TypeScriptは、JavaScriptに静的型チェックなどの機能を加えた言語です。

次のコードを比較してみましょう。

**JavaScript**

```js
function add(a, b) {
  return a + b;
}

add(10, "20"); // "1020"
```

**TypeScript**

```ts
function add(a: number, b: number) {
  return a + b;
}

add(10, "20"); // 型エラー
```

JavaScriptでは、数値と文字列を渡すと、意図しない文字列結合が起こる場合があります。

TypeScriptでは引数の型を指定できるため、このような誤りを実行前の型チェックで発見できます。

TypeScriptは通常、JavaScriptに変換して実行します。型情報を利用したエディターの補完や変更時のチェックも、大きなメリットです。

## 3. Python：AI・データ分析でよく使われる言語

Pythonは、比較的シンプルな文法と、豊富なライブラリを特徴とするプログラミング言語です。

AI・機械学習、データ分析、Web開発、作業の自動化など、幅広い分野で使われています。

例えば、数値のリストを合計する処理は次のように書けます。

```python
numbers = [10, 20, 30]
print(sum(numbers))
```

### なぜAI開発でPythonが使われるのか？

PythonがAI分野で広く使われている理由の一つは、関連するライブラリが充実していることです。

- NumPy：数値計算
- pandas：データの加工・分析
- scikit-learn：機械学習
- PyTorch：深層学習

これらを利用することで、開発者は数値計算や機械学習の仕組みをすべて自作する必要がありません。

また、Pythonのライブラリの内部では、性能が必要な部分がCやC++などで実装されていることもあります。

つまり、**Pythonが選ばれる理由は、文法の書きやすさだけではなく、周辺のライブラリや研究・開発環境が充実していること**にもあります。

## 4. C・C++・Rust：性能やメモリ管理が重要な分野

### C・C++

CやC++は、OS、組み込み機器、ゲームエンジンなど、コンピューターの資源を細かく扱う必要がある分野で使われています。

Cではポインタを通じてメモリを直接扱うことができ、C++ではオブジェクト指向やジェネリックプログラミングなどの機能も利用できます。

例えば、ゲームエンジンのUnreal EngineではC++が利用されています。

ただし、CやC++は自由度が高い一方で、メモリ管理の誤りなどに注意する必要があります。

### Rust

Rustは、性能とメモリ安全性の両立を重視して設計されたプログラミング言語です。

特徴的なのが、**所有権（Ownership）** という仕組みです。

Rustでは、値の所有者や参照の扱いにルールを設け、メモリに関する多くの問題をコンパイル時に防ぎます。

そのため、性能を求められるシステムソフトウェアなどで利用されています。

C/C++とRustの違いを考えるときは、単に実行速度を比較するのではなく、メモリの安全性や開発時の制約にも注目することが重要です。

## 5. Java・Kotlin・Swift・Dart：アプリ開発で使われる言語

### JavaとKotlin

Javaは、企業の業務システムやサーバー開発などで広く使われている言語です。JVM（Java Virtual Machine）という実行環境を利用することが特徴の一つです。

KotlinもJVM上で動作でき、Javaのコードやライブラリとの相互運用性があります。

Androidアプリ開発では、KotlinがGoogleによって積極的にサポートされています。Kotlinにはnull安全性など、開発時のミスを減らすための仕組みがあります。

### Swift

Swiftは、Appleのプラットフォーム向けのアプリ開発で広く使われる言語です。

iPhoneやMac向けのアプリでは、SwiftUIなどAppleが提供する開発フレームワークと組み合わせて利用できます。

### DartとFlutter

Dartはプログラミング言語で、FlutterはDartを利用するUIフレームワークです。

Flutterを使うと、AndroidとiOS向けのアプリで多くのコードを共有できます。

例えば、両OS向けに同じ機能を提供したい場合、Flutterは選択肢の一つになります。一方、特定のOSの機能を深く利用する場合は、SwiftやKotlinによるネイティブ開発が適していることもあります。

## 6. その他の言語：C#とGo

| 言語 | 主な用途 | 特徴 |
| --- | --- | --- |
| C# | Unityによるゲーム開発、.NETによるWeb開発 | Unityや.NETの開発環境と組み合わせやすい |
| Go | Webサーバー、クラウド・インフラ関連のツール | 比較的シンプルな言語設計と並行処理の仕組みを持つ |

## 7. 言語を比較するときの重要な視点

### 静的型付けと動的型付け

プログラミング言語には、型の扱い方に違いがあります。

| | 静的型付け | 動的型付け |
| --- | --- | --- |
| 代表例 | TypeScript、Java、Rust、Swift | JavaScript、Python |
| 型の検査 | 主に実行前 | 主に実行時 |
| 特徴 | 型の不整合を事前に発見しやすい | 型の宣言を省略して柔軟に記述しやすい |

ただし、静的型付けだから必ず安全、動的型付けだから必ず開発が速い、というわけではありません。

### 言語だけでなく周辺技術も重要

実際の開発では、プログラミング言語だけでなく、次のような技術も一緒に選びます。

| 種類 | 例 | 役割 |
| --- | --- | --- |
| 言語 | TypeScript、Python、Dart | プログラムを記述する |
| 実行環境 | Node.js、JVM | プログラムを実行する環境 |
| ライブラリ | NumPy、pandas | 特定の機能を再利用する |
| フレームワーク | Flutter、Spring Boot | アプリ開発の構造や仕組みを提供する |

Reactは一般にUIライブラリと分類されますが、アプリ開発の基盤としても利用されます。

## 8. 実際に言語を選んでみよう

次のようなものを作るとしたら、どの言語を選びますか？

| 作りたいもの | 言語の候補 | 選ぶ理由 |
| --- | --- | --- |
| ブラウザーで動くToDoアプリ | JavaScript / TypeScript | ブラウザーで動作し、画面操作を実装できる |
| 画像を分類するAI | Python | 機械学習ライブラリが豊富 |
| iPhone向けのアプリ | Swift | Apple向けの開発環境が充実 |
| Android・iOS両対応アプリ | Dart | Flutterを使ってコードを共有できる |
| 3Dゲーム | C++ / C# | Unreal EngineやUnityなどの開発環境がある |
| マイコンの制御 | C / Rust | 機器向けの開発環境やメモリ制御を利用できる |

ここで重要なのは、答えが必ず一つに決まるわけではないことです。

チームの経験、既存のコード、利用できるライブラリ、必要な性能などによって、適した言語は変わります。

## 9. まとめ

プログラミング言語を選ぶときは、文法や実行速度だけで判断するのではなく、次の点を考えます。

- 何を作りたいのか
- どこで動かすのか
- どのようなライブラリやフレームワークが利用できるか
- 性能・安全性・開発効率のどれを重視するか
- チームで開発・保守しやすいか

**プログラミング言語の特徴を理解することは、作りたいものを実現するための技術選定につながります。**
