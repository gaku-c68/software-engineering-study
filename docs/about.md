# 勉強会について

大学生を対象に、ソフトウェア開発に関わるさまざまな技術を学ぶ勉強会です。

## 目指すこと

幅広い分野に触れ、自分の興味やつくりたいものを見つけながら、最終的には参加者自身でソフトウェアを開発できるようになることを目指します。

## 扱う分野

Web、モバイル、AR・VR、AI、IoT、インフラなどを対象とします。分野同士のつながりにも目を向け、開発に必要な知識を広げていきます。

具体的なカリキュラム、学習順序、教材は今後検討し、このサイトに追加していきます。

## このサイトの使い方

- **講義中**：手元でページを開き、説明と照らし合わせて確認します。
- **講義後**：気になった内容を読み返し、自分のペースで復習や自習に取り組みます。

ページは上部のナビゲーション、サイドバー、サイト内検索から探せます。スマートフォンではメニューからページを選択できます。
